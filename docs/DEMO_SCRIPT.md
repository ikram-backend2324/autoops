# Сценарий демо-видео (2 минуты)

**Цель:** за 2 минуты показать клиенту, что сервер сам замечает сбои, лечит себя и сообщает в Telegram.
**Формат:** запись экрана 1920×1080 + телефон с Telegram (снимается вторым устройством или через Telegram Desktop,
вставленный «картинкой в картинке» в правый нижний угол). Музыка без слов, субтитры на русском/английском.

## Подготовка (до записи)
1. `make local-clean && make local-up`, подождать 10 минут, чтобы графики в Grafana заполнились.
2. Впишите реальные `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` в `local/.env` → `docker compose -f local/compose.yml up -d alertmanager notify-relay`.
3. Откройте вкладки: Grafana «AutoOps · Обзор сервера», «AutoOps · Контейнеры», http://localhost:8088.
4. Терминал: крупный шрифт (18–20 pt), тёмная тема, `clear`.
5. Для кадров provisioning запишите заранее реальный `make provision` на тестовом VPS (или используйте запись вывода Ansible) — его ускорим ×20.

## Советы
* Сцену CPU (4 минуты ожидания) в 2-минутное видео не ставьте — достаточно упомянуть в итоговой таблице.
* Перед записью сценария с БД убедитесь, что предыдущие алерты закрылись (`http://localhost:9093` пустой).
* Делайте 2 версии: 2 минуты для LinkedIn/Upwork и 30 секунд (только chaos-db с телефоном) для Reels/Stories.
* Оригинал терминала сохраняйте: `script -q chaos.log make chaos-auto` — пригодится для GIF в README (`agg`/`asciinema`).
