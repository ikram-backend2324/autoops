# Как продавать AutoOps: цены, расчёт, каналы, тексты

> Цифры — ориентиры на 2026 год. Пересматривайте их после первых 3–5 клиентов.

## 1. Пакеты и цены

| Услуга | Что входит | Узбекистан | Фриланс / зарубеж |
|---|---|---|---|
| **«Сервер под ключ»** | provisioning + защита, деплой 1 приложения, HTTPS, мониторинг + дашборды, алерты в Telegram, self-healing, бэкапы с проверкой восстановления, документация и передача доступов | **$200–600** | **$500–1500** |
| **CI/CD-настройка** (отдельно) | GitHub Actions: тесты → образ → деплой → health-check → автооткат → Telegram | $150–400 | $300–800 |
| **Ежемесячная поддержка** (за сервер) | реакция на алерты, обновления, проверка бэкапов, еженедельный отчёт, ежемесячный созвон/отчёт | **$50–200/мес** | **$150–500/мес** |
| **Аудит существующего сервера** | проверка безопасности, бэкапов, мониторинга, отчёт с рисками и планом | $100–300 | $200–500 |
| **Миграция проекта** | с shared-хостинга/«ручного» сервера в Docker + весь стек AutoOps | $300–1000 | $600–2000 |
| Доп. приложение на том же сервере | ещё один проект клиента | +$50–150 | +$100–300 |

Где внутри диапазона: нижняя граница — одно Django/Docker-приложение, готовый Dockerfile, клиент сам даёт DNS;
верхняя — нет Docker, несколько сервисов, перенос базы, срочность, требования по хранению данных в UZ.

### Почему поддержка — главное
Разовая настройка оплачивает месяц. Поддержка оплачивает **каждый** месяц, а после автоматизации почти не
требует времени: алерты и self-healing делают 90 % рутины, отчёты формируются сами.

## 2. Сколько времени уходит после автоматизации

| Этап | Первый клиент | С AutoOps (5-й клиент и дальше) |
|---|---|---|
| Созвон, сбор доступов (чек-лист из DATA.md) | 2 ч | 1 ч |
| Docker-изация приложения клиента (если нет) | 4–8 ч | 2–4 ч |
| `make provision` + `make deploy` + DNS + HTTPS | 4 ч | 0.5–1 ч |
| CI/CD | 3 ч | 0.5–1 ч |
| Перенос данных, проверка, go-live чек-лист | 3 ч | 1–2 ч |
| Документация и передача | 2 ч | 0.5 ч (шаблоны готовы) |
| **Итого «под ключ»** | **18–22 ч** | **5–9 ч** |

**Поддержка одного сервера в месяц:** ~1–2 ч (обновления через `make update`, взгляд на еженедельный отчёт,
квартальный DR-тест, разбор 0–3 инцидентов, которые self-healing не закрыл).

### Сколько это даёт (пример)
| Показатель | Консервативно | Хорошо |
|---|---|---|
| Клиентов на поддержке | 10 | 25 |
| Средний чек поддержки | $80 (UZ) | $150 (микс UZ + зарубеж) |
| Время на поддержку | 10–20 ч/мес | 25–50 ч/мес |
| **Доход с поддержки** | **$800/мес** | **$3 750/мес** |
| + новых «под ключ» в месяц | 2 × $350 | 3 × $700 |
| **Итого** | **≈ $1 500/мес** | **≈ $5 850/мес** |

Один человек комфортно ведёт **20–30 серверов** при условии стандартизации (один стек, одни алерты,
центральная Grafana — см. PRODUCTION.md §6). Дальше нужен второй инженер на дежурства.

## 3. Кому продавать

1. **Веб-студии без DevOps** — делают сайты и отдают клиенту «как есть». Вы — их подрядчик на инфраструктуру
   (white-label: алерты идут студии, студия перепродаёт с наценкой).
2. **Стартапы** — 1–5 разработчиков, сервер настраивал «тот, кто ушёл».
3. **Интернет-магазины** — каждый час простоя = потерянные заказы; бэкапы и алерты понятны без объяснений.
4. **Компании с «одним сервером, который никто не трогает»** — бухгалтерия, CRM, 1С-интеграции, внутренние порталы.
5. **Ваши текущие клиенты по разработке** — самые тёплые: вы уже знаете их проект. Начните с них.

## 4. Каналы и что там делать

| Канал | Действие |
|---|---|
| Свои клиенты | письмо/звонок: «бесплатно проверю ваш сервер» → отчёт аудита → предложение |
| Telegram-сообщества разработчиков UZ | полезные посты (как не потерять базу, разбор инцидента), демо-видео chaos, без спама |
| LinkedIn | пост с chaos-видео + кейс «до/после»; комментарии под постами CTO/фаундеров из UZ/СНГ |
| Upwork / Freelancer | профиль DevOps + gig ниже; отклик в первые 30 минут после публикации заказа |
| Kwork | услуга «Настрою сервер под ключ: Docker, HTTPS, мониторинг, бэкапы» с фиксированной ценой |
| Локальные IT-мероприятия, IT Park | мини-доклад «Как сервер лечит себя сам» с живым chaos-демо |

**Входная дверь — бесплатный аудит** (30–60 минут работы): скрипт-проверка + отчёт на 1 страницу с 3–5 рисками
(«бэкапов нет», «порт 5432 открыт в интернет», «диск заполнится через 3 недели»). Конверсия аудита в заказ
обычно намного выше холодного предложения.

**Главный аргумент — chaos-видео** (сценарий: [DEMO_SCRIPT.md](DEMO_SCRIPT.md)): клиент видит, как сервер
«ломают», а в Telegram через минуту приходит «🔧 восстановлено». Это убеждает лучше любого текста.

### Кейс «до / после» (шаблон)
| | До | После AutoOps |
|---|---|---|
| Узнаём о падении | от клиентов, через часы | Telegram через 1 мин |
| Восстановление | вручную, 30–120 мин | автоматически, 10–70 с |
| Бэкапы | «где-то были», не проверялись | ежедневно, вне сервера, восстановление проверяется еженедельно |
| HTTPS | истёк сертификат — сайт «опасен» | продлевается сам, алерт за 14 дней |
| Деплой | FTP/ssh вручную, страшно | push в main → автотесты → автооткат |

## 7. SLA — что обещать и что нет

**Обещать:**
| Параметр | Базовая поддержка | Расширенная |
|---|---|---|
| Реакция на critical-алерт (сайт/БД недоступны) | 1 ч в рабочее время, 4 ч ночью | 30 мин 24/7 |
| Реакция на warning | следующий рабочий день | 4 ч |
| Обновления безопасности | автоматически + ежемесячный `make update` | еженедельно |
| Проверка восстановления бэкапа | еженедельно (автоматически) + ежеквартальный DR-тест | ежемесячный DR-тест |
| Отчёт | еженедельно в Telegram, ежемесячно PDF | + созвон |

**Не обещать:** «100 % аптайм»; исправление ошибок в коде клиента (это разработка — отдельно);
ответственность за проблемы провайдера/ДЦ и DNS-регистратора; скорость работы плохо написанного приложения;
восстановление данных старше политики хранения (7 дневных / 4 недельных / 6 месячных).
Формулируйте аптайм как **цель** (99.5–99.9 %), а не гарантию, и измеряйте его blackbox-метрикой.

## 8. Договор / оферта на поддержку — основные пункты

1. **Предмет:** администрирование и мониторинг серверов из приложения №1 (список, характеристики, приложения).
2. **Состав услуг:** мониторинг 24/7 (автоматический), реакция на алерты в сроки SLA, обновления, бэкапы и их проверка, отчёты.
3. **Что не входит:** разработка, исправление бизнес-логики, контент, работы вне перечня — по отдельной ставке ($/час).
4. **SLA:** время реакции (не решения!) по уровням, способ связи (Telegram-группа), окно плановых работ.
5. **Обязанности клиента:** оплата сервера/S3/домена, своевременная оплата услуг, предупреждение о нагрузках/акциях, не менять конфигурацию без согласования.
6. **Доступы и конфиденциальность:** NDA; доступы принадлежат клиенту; по окончании — передача всего кода, паролей (vault) и документации в течение 5 рабочих дней.
7. **Персональные данные:** где хранятся данные и бэкапы; соответствие закону РУз «О персональных данных».
8. **Ответственность:** ограничена суммой оплаты за последний месяц; форс-мажор, сбои провайдеров.
9. **Оплата:** предоплата помесячно; цена фиксирована на 6–12 месяцев; индексация.
10. **Срок и расторжение:** бессрочно с уведомлением за 30 дней; процедура передачи дел.
