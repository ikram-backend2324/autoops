AUTOOPS - HOW TO RUN FROM ZERO
==============================

A. LOCAL DEMO (your laptop, no server needed)
----------------------------------------------
1) Install Docker Desktop (Windows: Settings -> Resources -> WSL integration -> enable "Ubuntu").
2) Windows only: open "Ubuntu" (WSL2) and run:
      sudo apt update && sudo apt install -y make git curl python3
   Linux/macOS: install make, git, python3.
3) Go to the project:
      cd /mnt/d/start-up/autoops          (WSL path of D:\start-up\autoops)
4) Create the env file (make local-up also does this automatically):
      cp local/.env.example local/.env
   local/.env contents (demo values, change if you want):
      SERVER_NAME=local-demo
      APP_NAME=sample
      APP_IMAGE=autoops/sample-app
      APP_TAG=local
      APP_DOMAIN=localhost
      LOCAL_WEB_PORT=8088                 <- change if 8088 is busy
      APP_ENV_FILE=../../local/.env
      DJANGO_SECRET_KEY=local-demo-secret-key-change-me
      DJANGO_DEBUG=0
      POSTGRES_DB=app
      POSTGRES_USER=app
      POSTGRES_PASSWORD=local-demo-postgres
      GUNICORN_WORKERS=2
      CELERY_CONCURRENCY=2
      CHAOS_ENABLED=1
      CHAOS_TOKEN=local-chaos-token
      GRAFANA_ADMIN_USER=admin
      GRAFANA_ADMIN_PASSWORD=autoops
      GRAFANA_URL=http://localhost:3000
      TELEGRAM_BOT_TOKEN=                  <- optional: token from @BotFather
      TELEGRAM_CHAT_ID=                    <- optional: chat id (see docs/DATA.md)
      AUTOOPS_RULES_DIR=../../local/generated/rules
      AUTOOPS_TARGETS_DIR=../../local/targets
      AUTOOPS_TEXTFILE_DIR=textfile
      S3_ACCESS_KEY=autoops
      S3_SECRET_KEY=autoops-local-secret
      RESTIC_REPOSITORY=s3:http://s3:7070/autoops-backups
      RESTIC_PASSWORD=local-demo-restic-password
5) Start everything:
      make local-up
6) Open:
      App          http://localhost:8088   (health: /health/)
      Grafana      http://localhost:3000   admin / autoops
      Prometheus   http://localhost:9090
      Alertmanager http://localhost:9093
      Alerts log   make local-alerts       (or http://localhost:9095/events)
7) Try it:
      make backup            make verify-restore      make restore APP=sample
      make chaos             (5 failure scenarios, report -> docs/chaos-report.md)
      make test              make lint                make molecule       make test-deploy
      make screenshots       (Grafana screenshots -> docs/screenshots)
8) Stop:  make local-down    (keep data)   |   make local-clean (delete data)

Without make (Git Bash on Windows), the same thing:
      export MSYS_NO_PATHCONV=1
      cp local/.env.example local/.env
      python scripts/dev/fast_rules.py
      docker network create autoops
      docker compose -f local/compose.yml up -d --build
      scripts/chaos/run_all.sh

B. REAL SERVER (Ubuntu 22.04/24.04 VPS, domain, Telegram bot, S3 bucket)
--------------------------------------------------------------------------
How to get each account/key: docs/DATA.md
1) SSH key:            ssh-keygen -t ed25519   (add .pub to the VPS at creation)
2) DNS:                A records  app.example.uz  and  grafana.example.uz  -> server IP
3) Inventory:          cp ansible/inventory/hosts.example.yml ansible/inventory/hosts.yml
                       edit: ansible_host (IP), autoops_base_domain, autoops_apps (name, image, tag, domain)
4) Secrets env (vault): cp ansible/inventory/group_vars/all/vault.example.yml ansible/inventory/group_vars/all/vault.yml
   fill these values (generate passwords with: openssl rand -base64 32):
      vault_telegram_bot_token      vault_telegram_chat_id
      vault_grafana_admin_password
      vault_restic_repository       (s3:https://<endpoint>/<bucket>/<server>)
      vault_restic_password         (KEEP A COPY in a password manager!)
      vault_s3_access_key_id        vault_s3_secret_access_key
      vault_deploy_public_keys      (public key used by GitHub Actions)
      vault_registry_username/password  (only for private GHCR images)
      vault_app_secrets: <app>: postgres_password, django_secret_key
   then encrypt:  make tools-image
                  docker run --rm -it -v "$PWD:/work" -w /work autoops/tools:local ansible-vault encrypt ansible/inventory/group_vars/all/vault.yml
5) Provision + deploy:
      make provision EXTRA="-e ansible_user=root"     (first time, as root)
      make deploy
      make server-backup RUN=1
6) Check:  curl -I https://app.example.uz/health/   -> 200 ;  Grafana: https://grafana.example.uz
   Server-side env files are generated by Ansible: /opt/autoops/apps/<app>/.env, tag.env,
   /opt/autoops/stacks/monitoring/.env, /etc/autoops/watchdog.env, /etc/autoops/backup.env

C. GITHUB CI/CD
---------------
Secrets: SSH_PRIVATE_KEY, SERVER_HOST, SERVER_PORT, SERVER_KNOWN_HOSTS, TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID
Variables: APP_NAME, APP_DOMAIN, DEPLOY_ENABLED=true
Push to main -> tests -> image to GHCR -> deploy -> health check -> auto rollback -> Telegram.

More: docs/RUN.md (step by step + troubleshooting), docs/PRODUCTION.md, docs/BUSINESS.md
